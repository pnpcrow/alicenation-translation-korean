# Alicenation 한국어 패치

대상: Windows / 게임 1.0.5 / 한국어 패치 v1

일본어 리소스를 번역 기준으로 삼고 다른 언어를 비교 자료로 사용한다.
게임의 중국어 간체 슬롯을 한국어로 대체한다.

## 작업 원칙

- 게임 원본의 경로와 SHA-256을 기록하고 작업 폴더의 사본에서 수정한다.
- 원본 게임, 추출한 전체 원문과 빌드 중간 산출물은 Git에 넣지 않는다.
- 번역문, 용어집, 제작 도구, 그래픽 수정본, 인스톨러 코드는 단계별로 커밋한다.
- 패치는 버전과 원본 해시를 검증하며 설치 전 백업을 만든다.
- 복구는 패치가 변경한 파일만 검증된 백업으로 되돌린다.

## 포함 내용

텍스트 7,410항목, 언어표 밖 화면 문구 90개와 이미지 43개를 한국어로 바꾼다.
사용자가 제공한 학교안심 그림일기 글꼴과 한국어 단어 단위 줄바꿈을 적용한다.
Rust 인스톨러는 원본 검사, 백업, 패치, 원상 복구를 지원한다.

배포 파일은 `dist/Alicenation-1.0.5-Korean-v1.zip`에 만든다.
압축을 풀고 `Alicenation-Korean-v1.exe`에서 게임 폴더를 선택해 적용한 뒤,
게임 언어를 **한국어**로 선택한다. 설치·복구 방법은 `docs/release-readme.txt`를 참고한다.

작업 중 Steam 설치본이 1.0.6으로 업데이트되었다. 이 배포판은 **1.0.5 전용**이며
1.0.6에는 적용하지 않는다. 검증된 1.0.5 원본은 로컬 `work/baseline-1.0.5`에 보존했다.
게임 원본과 빌드 중간 파일은 배포하거나 Git에 포함하지 않는다.

실제 타이틀·언어 선택·프롤로그·초반 튜토리얼·도움말과 설치·복구를 확인했다.
모든 이야기 분기와 엔딩을 끝까지 플레이한 것은 아니다. 자세한 검증 기록은
`docs/qa.md`, 재빌드 절차는 `docs/installer.md`에 있다.
