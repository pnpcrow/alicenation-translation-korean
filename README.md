# Alicenation 한국어 패치

대상: Windows / 게임 1.0.5 / 한국어 패치 v1 (제작 중)

일본어 리소스를 번역 기준으로 삼고 다른 언어를 비교 자료로 사용한다.
게임의 중국어 간체 슬롯을 한국어로 대체한다.

## 작업 원칙

- 게임 원본의 경로와 SHA-256을 기록하고 작업 폴더의 사본에서 수정한다.
- 원본 게임, 추출한 전체 원문과 빌드 중간 산출물은 Git에 넣지 않는다.
- 번역문, 용어집, 제작 도구, 그래픽 수정본, 인스톨러 코드는 단계별로 커밋한다.
- 패치는 버전과 원본 해시를 검증하며 설치 전 백업을 만든다.
- 복구는 패치가 변경한 파일만 검증된 백업으로 되돌린다.

## 진행 단계

1. 리소스·언어·글꼴·그래픽 조사 및 원본 목록 작성
2. 일본어 기준 번역과 언어별 대조, 용어 통일
3. 한국어 글꼴 및 그래픽 적용, 간체 중국어 슬롯 교체
4. 실제 게임 표시 및 번들 무결성 검증
5. Rust 패치·복구 인스톨러와 v1 배포 파일 제작

아직 배포 가능한 완성본이 아니다. 검증 결과와 실행 방법은 작업에 맞춰 갱신한다.
