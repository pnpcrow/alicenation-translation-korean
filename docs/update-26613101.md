# 1.1.0 Steam 빌드 26613101 대응

2026-11-12 Steam 설치 기록과 캐시 public 브랜치에서 빌드 26613101을 확인했다.
앱 3755350, 디포 3755351, 매니페스트는 `4379730585194860078`이다.
원본 398개, 647,929,640바이트를 Steam 경로·크기·SHA-1 및 SHA-256으로 대조했다.
작업 사본의 기존 패치 잔여물 23개는 검증된 원본 백업에서 확보했다.

## 변경 내용

이전 빌드 26489605 대비 같은 경로의 파일 11개가 바뀌고 번들 8개가 교체됐다.
Unity 파일 374개를 읽었으며 파일 읽기 오류는 없다. 네 언어 번역표에
`Label_Eyes`가 한 개씩 추가됐다. 일본어·영어·번체는 7,501개, 간체는 1,636개다.
기존 항목의 변경·삭제는 없으며 번역표는 무손실 추출·재직렬화했다.
[번역 결정 기록](translation-decisions.md)에 따라 새 항목은 ‘왕눈이 모드’로 번역한다.

왕눈이 모드의 CardEyesConfig, 눈 스프라이트·텍스처와 카드·선택·보상 화면의
새 눈 표시 오브젝트가 추가됐다. 공용 프리팹에는 새 설정 문구 두 개와 체크
상자·체크 표시가 있다. 새 그림 세 개에는 글자가 없어 그대로 보존한다.
그 밖에 변경 번들의 텍스처 82개는 디코딩한 픽셀이 이전과 같다.
기존 한글화 이미지 43개, 로고 잘림 수정과 튜토리얼 Sprite 52개를 유지한다.
폰트 번들도 이전 빌드와 같다.

CardEyesConfig가 resources.assets의 1479번에 삽입되면서 이후 오브젝트 번호와
연결 참조가 한 칸씩 이동했다. 번역표·TMP 설정 위치를 이에 맞춰 조정하며
최신 원본의 카드 정보와 새 눈 설정을 보존한다. 이야기 스크립트 17개의
명령 내용은 무손실 파싱해 이전 빌드와 동일함을 확인했다.

## 실행 코드와 저장 화면

GameAssembly.dll과 metadata가 새로 빌드됐다. Il2CppDumper와 역어셈블 결과로
LocalizationManager.LocalizationText의 RVA `0x51E310`, 파일 위치 `0x51D510`,
CN 분기 `+0x59`를 확인했다. 함수 0xB3바이트의 SHA-256을 고정하고 기존과 같은
두 바이트 분기만 바꾸어 간체 슬롯에서 한국어 번역표를 조회한다.

저장 슬롯의 유일한 `Chapter {0}` 리터럴은 metadata 엔트리 `0x6C00`, 데이터
`0x383C9`로 이동했다. 전체 metadata 해시와 위치를 고정하고 ‘제{0}장’으로
바꾼다. 다른 리터럴과 파일 길이는 유지한다. 이전 metadata 검증값도 보존한다.
TMP 설정의 두 내부 참조가 이동했지만 한글 줄바꿈 필드 위치 296과 길이 300은
같다. 새 원본 해시를 별도로 고정해 마지막 bool만 바꾼다.

- globalgamemanagers SHA-256: `8502addad4d325e19b1bfa521a47b8772766f74faece7a971497b523a520b122`
- resources.assets SHA-256: `45c1d6a154520de4ef72a99d996e2ae8a65ba95040367350f116f5a1a845c1b9`
- GameAssembly.dll SHA-256: `d1e3f9f601fb25cce85c3458e83dc7cd2cc689246b49222495b682f27e175b9d`
- 번역 조회 함수 SHA-256: `2778d4f4ac8e045598ca3d12ca4ab11a6bdc4fef863009288d378176e6380b3c`
- metadata SHA-256: `5c02a68ce682fd62a62cdb9abd0f8f0e0ef54b784be028047c534377cb0a7d3a`
