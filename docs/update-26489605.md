# 1.0.12 Steam 빌드 26489605 대응

2026-11-08 확인한 Steam 공개 브랜치·설치본은 빌드 26489605이며 게임 내부 버전은
1.0.12 그대로다. 앱 3755350, 디포 3755351, 매니페스트는 `8648115138595195027`이다.
Steam의 경로·크기·SHA-1과 로컬 SHA-256으로 원본 398개, 647,876,861바이트를 확인했다.
기존 한글화 잔여물 26개는 검증된 백업에서 작업 사본의 원본을 확보했다.

## 변경 범위

이전 빌드 26437071에서 resources.assets, boot.config, Addressables의 catalog.json과
settings.json이 바뀌고 폰트 번들 하나가 교체됐다. 그 외 파일은 동일하다.
Unity 파일 374개를 읽었으며 파일 읽기 오류는 없다.

일본어·영어·번체는 각각 키 2개가 교체됐으며 총 7,500항목이다. 간체 1,635항목은
그대로다. 네 언어 모두 무손실 추출·재직렬화를 확인했다.
3장 망원경 장면의 서술은 눈앞의 광경을 ‘받아들이기 어려웠다’는 의미로 수정했다.
기존 의사 대사 키 연결은 정식 키로 편입해 중복 연결 없이 한국어 7,500항목을 넣는다.
[번역 결정 기록](translation-decisions.md)에 문맥과 비교 결과를 남겼다.

이야기 스크립트 17개를 무손실 파싱해 비교했다. Chapter3/script9_2의 서술 키와
CardMeet/Hollow_Force_First의 조건이 바뀌었다. 후자는 `HasMeili()` 앞에
`!MapRace(Lab)&&` 조건이 추가됐다. 모든 이야기 명령은 최신 원본 그대로 보존한다.

## 폰트와 그래픽

새 폰트 번들은 `fonts_assets_all_cee264659120a76c6e3e2f163a053269.bundle`이다.
Lolita의 미리 저장된 글자 704개와 OPPOSans의 13개가 비워지고 Lolita의 추가
글자 이미지 7개가 제거됐다. 원본 글꼴 파일과 WinkySans는 이전 빌드와 같다.
새 폰트 번들의 오브젝트·글자 정보·이미지를 기준으로 한글 대체 글꼴을 추가하며,
원본 글자 이미지와 비한글 정보 보존을 검사한다.

한글화 대상 이미지 43개와 프리팹은 이전 빌드와 같다. 기존 이미지 생성 결과,
로고 전체 사각 메시, 튜토리얼 Sprite 52개, 별도 화면 문구 164개와 저장 화면의
장 번호 번역을 유지한다.

## 실행 코드와 빌드 판별

실행 파일, GameAssembly.dll, metadata와 globalgamemanagers는 이전 빌드와 같다.
번역 조회 분기 및 `Chapter {0}` 문자열 위치도 같다. 인스톨러 1.2.7은 콘텐츠
설정과 패치 대상의 원본 해시까지 확인해 두 1.0.12 빌드를 구분한다.
새 백업은 `backup/1.0.12-b26489605/`에 보관한다.

- resources.assets SHA-256: `75ba4769ed926a19cc06b4161daa0c6a2792f88f8bd2f05d60772fb7cf27ae37`
