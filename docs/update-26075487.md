# 1.0.10 Steam 빌드 26075487 대응

2026-10-21에 확인한 Steam 빌드 26075487은 게임 내부 버전이 여전히 1.0.10이다.
이전 빌드 26040541과 섞이지 않도록 제작·설치·백업 식별자는 `1.0.10-b26075487`로 구분한다.
사용자에게는 게임 버전과 Steam 빌드를 함께 표시한다.

## 원본과 변경 범위

- 앱 3755350 / 디포 3755351 / 매니페스트 `8710597363717768207`
- 원본 398파일, 647,845,188바이트. Steam 매니페스트의 경로·크기·SHA-1 및 로컬 SHA-256을 확인했다.
- 기존 패치가 남은 20파일은 새 매니페스트와 일치하는 검증된 원본 백업으로 작업 사본을 구성했다.
- 같은 경로 8파일 변경, Addressables 번들 4개 이름 변경, libvips DLL 2개 제거.
- 일본어·영어·번체 표 각 7,438항목, 간체 원본 1,635항목. 네 표 모두 추출·재직렬화가 무손실이다.
- 일본어 기준 키 3개 추가, 1개 삭제. 기존 키의 일본어 값 변경은 없다.
- 변경된 Texture2D는 없다. 기존 한글화 이미지 43개와 타이틀 Sprite 잘림 수정은 유지한다.

숫자·시각 예시는 그대로 보존했다. 별도 화면 문구는 총 106개다.

## 빌드 식별과 복구

실행 파일은 이전 빌드와 같지만 `globalgamemanagers` SHA-256은 다르다.
제작 도구는 bundleVersion과 해당 파일 해시를 함께 확인한다. 알려지지 않은 1.0.10
빌드는 거부한다. 인스톨러도 실행 파일·버전 파일과 모든 패치 대상 원본 해시를 검증한다.

- 이전 버전 파일: `b279c11c1d3a4ff01942a52e4fe56013db0c3a1481b3d588e29dc28b00c30565`
- 이번 버전 파일: `1e40fc19fb6bda399b8f778913c1c5fd2c549ef459f41325fd334ecb99818d05`
- 새 LocalizationText 파일 오프셋: `0x51CC50`, 길이 `0xB3`
- 해당 함수 SHA-256: `0dac98c594a2b814aa3bcf3ca595abeaa4454397e8e7d40650c39c4f2d3111a8`
- 간체 키 반환 분기 `0x51CCA9`: `75 4A` → `90 90`

새 코드와 메타데이터를 함께 분석해 기존과 같은 언어 분기임을 확인했다.
예전 빌드의 오프셋을 그대로 사용하지 않는다. 인스톨러 1.2.2는 같은 게임 버전의
다른 빌드를 별도 백업 폴더로 관리하고 이전 설치 기록을 history에 보존한다.
원본 확인이 끝나기 전에는 이전 패치 위에 적용하거나 과거 빌드로 강제 복구하지 않는다.
