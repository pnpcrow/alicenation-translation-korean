# 1.0.11 Steam 빌드 26208729 대응

2026-10-26에 확인한 최신 설치본은 게임 1.0.11, Steam 빌드 26208729다.
이전 1.0.10 빌드 26123177과 비교해 텍스트, 저장·선택 화면, 코드가 변경되었다.

## 원본과 변경 범위

- 앱 3755350 / 디포 3755351 / 매니페스트 `2915677387946575215`
- Steam 매니페스트의 경로·크기·SHA-1과 로컬 SHA-256으로 확인한 원본 398파일, 647,881,104바이트
- 설치본에 남은 이전 패치 21파일은 이번 Steam 원본과 일치하는 백업으로 작업 사본을 구성
- 같은 경로 7파일 변경: GameAssembly, boot.config, globalgamemanagers, globalgamemanagers.assets, metadata, resources.assets, catalog
- 폰트 번들 1개와 prefab 번들 5개 교체: 선택 카드·선택 항목·저장 항목·저장 화면·공용 prefab
- Unity 파일 374개 분석, 파일 읽기 오류 없음

## 번역과 그래픽

일본어·영어·번체는 각각 7,500항목, 간체는 1,635항목이며 네 언어 모두 무손실로
추출·재직렬화했다. 일본어·영어·번체에서 65개 키가 추가되고 3개가 제거되었다.
기존 키의 번역 값은 바뀌지 않았다. 추가분은 새 대사 62개와 등장인물이 메리에서
노아로 바뀐 대사 3개다. 일본어를 기준으로 영어와 비교하고, 이야기 스크립트의
화자·전후 대사를 확인해 번역했다. 기존 고유명사와 말투를 유지했다.

저장 화면·저장 항목·공용 prefab에서 ‘Chapter 1’ 33개가 추가되었고, 임무 정보
자리표시자 33개의 원문이 바뀌었다. 기존 번역 대상 8개를 갱신하고, 새 장 표시
33개와 나머지 임무 자리표시자 25개를 포함해 정적 화면 문구 164개를 검증한다.
저장 화면의 새 배치 정보는 보존하며, 변경된 선택 화면에는 원문 추가가 없다.

폰트 아틀라스 외에 저장 화면의 버튼·프레임 텍스처 4개가 변경되었다. 모두 글자가
없는 배경이므로 새 원본을 보존한다. 기존 이미지 생성 결과 43개를 재사용하고,
튜토리얼 Sprite 52개와 한글 로고의 전체 사각 메시·픽셀을 검증한다.

## 실행 중 장 번호

새 `Game.SaveItem.Refresh`는 언어표를 거치지 않고 문자열 `Chapter {0}`을 직접
사용한다. 프리팹 문구만 바꾸면 실제 저장 슬롯에는 영어가 다시 표시된다.
이번 패치는 metadata의 해당 문자열 한 개를 `제{0}장`으로 바꾼다.
공용 문자열이므로 다른 언어를 선택해도 장 번호는 한국어로 표시된다.

- 원본 metadata SHA-256: `0804c92ab0f6138db02d540a2a1ae1309ef7307576eafb1e92d2d9c860ee12d0`
- 문자열 항목 위치 `0x6BF0`, 데이터 위치 `0x38377`
- UTF-8 길이 11→9, 남은 두 바이트는 0으로 채움
- 파일 크기·모든 문자열 시작 위치·나머지 문자열과 다른 바이트 보존 검증

metadata 패치 경로는 인스톨러에서 1.0.11에만 허용한다. 패치·백업·복구의 기존
파일 해시 검증에 포함되며 임의로 수정된 metadata는 복구 전에 거부한다.

## 버전과 코드 확인

현재 GameAssembly와 metadata를 함께 Il2CppDumper로 분석했다. LocalizationText의
CN 분기는 여전히 원문 키를 반환한다. 다른 언어와 같은 번역표 조회 경로를 쓰도록
검증된 조건 분기 두 바이트만 바꾼다.

- 함수 RVA `0x51DA50`, 파일 오프셋 `0x51CC50`, 길이 `0xB3`
- 함수 SHA-256: `271d081e7ed71d2a1069889c33fc715c42efc1c911c2912fd71946e450fe44ad`
- 분기 파일 오프셋 `0x51CCA9`, `75 4A` → `90 90`
- globalgamemanagers SHA-256: `2ae7742d79578a1b6042da2de52380d98b4907bff3f1cd661259c7284a8e63dd`

인스톨러 1.2.4는 실행 파일·globalgamemanagers·Addressables settings.json을 확인하고
29개 패치 대상의 원본 해시를 모두 검증한다. 백업은 `backup/1.0.11/`에 보관한다.
이전 릴리즈와 백업을 유지하며, 업데이트된 원본에 예전 파일을 강제 복구하지 않는다.
