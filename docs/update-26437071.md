# 1.0.12 Steam 빌드 26437071 대응

2026-11-05 확인한 게임 내부 버전과 Steam 공개 브랜치·설치본은 1.0.12 / 빌드
26437071이다. 앱 3755350, 디포 3755351, 매니페스트는 `8735438933586970766`이다.
Steam의 경로·크기·SHA-1과 로컬 SHA-256으로 원본 398개, 651,638,328바이트를 확인했다.
기존 한글화 잔여물 26개는 검증된 백업에서 작업 사본의 원본을 확보했다.

## 변경 범위

이전 빌드 26301409에서 resources.assets, globalgamemanagers, boot.config,
Addressables catalog.json이 바뀌고 폰트 번들 하나가 교체됐다. 그 외 파일은 동일하다.
Unity 파일 374개를 읽었으며 파일 읽기 오류는 없다.

일본어·영어·번체 7,500항목과 간체 1,635항목은 이전 빌드와 같다. 네 언어 모두
무손실 추출·재직렬화를 확인했다. 일본어 기준 번역 7,500항목과 이전 빌드에서
추가한 의사 대사 키 연결 1개를 유지하여 한국어 슬롯에는 7,501항목이 들어간다.
연결 대상의 일본어 원문과 실제 이야기 명령 위치도 다시 검사한다.

resources.assets의 변경 오브젝트는 ChapterTask(1499), Chapter5(1501) 두 개뿐이다.
17개 이야기 스크립트를 무손실 파싱해 비교했다. `BossHp<BossMinHp+1` 조건과
`Task504`로 이어지는 명령들이 ChapterTask / Main5_5_NextTurn에서
Chapter5 / UnUseObsidianKey로 옮겨졌다. 두 스크립트 모두 최신 원본 그대로 보존한다.

## 폰트와 그래픽

새 폰트 번들은 `fonts_assets_all_e36ae4f7e42504b645ad0ab000cf4e4f.bundle`이다.
기존 오브젝트를 유지하면서 Lolita 글자 이미지(Texture2D) 7개가 추가됐다.
Lolita의 미리 저장된 글자 수는 0 → 704, OPPOSans는 0 → 13, WinkySans는
87 → 85로 바뀌었다. 세 폰트의 원본 글꼴 데이터 자체는 동일하다.

최신 원본 폰트의 글자·배치·이미지와 새 오브젝트를 보존한 채 학교안심 그림일기
한글 대체 글꼴을 추가한다. 패치 검증에서 원본 글자 이미지 바이트, 비한글 문자
매핑, 기존 글자 정보와 이미지 참조가 보존되는지 별도로 확인한다.

한글화 대상 이미지 43개와 프리팹은 이전 빌드와 같으므로 검증된 이미지 생성
결과를 사용한다. 로고 전체 사각 메시, 튜토리얼 Sprite 52개, 별도 화면 문구
164개와 저장 화면의 장 번호 번역을 유지한다.
