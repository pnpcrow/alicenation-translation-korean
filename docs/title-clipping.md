# 메인 화면 한글 로고 잘림 수정

2026-10-19, 게임 1.0.10용 v1 r2에서 수정했다.

## 원인

생성된 `assets/images/title_ko.png`에는 글자·토끼 귀·테두리가 온전히 있다.
원본은 1,254×1,254이고 게임에는 원래 텍스처 크기인 1,024×1,024로 리샘플링한다.
해상도 차이나 이미지 자체의 잘림이 원인이 아니었다.

텍스처만 바꾸고 중국어 `Title_CN`의 Sprite 정보를 유지한 것이 원인이다.
기존 Sprite는 151개 꼭짓점·149개 삼각형으로 중국어 글자 윤곽을 따라 그리며,
textureRect도 약 796×676 영역으로 좁혀져 있었다. 한국어 로고 모양과 달라서
토끼 귀, 글자 바깥쪽, 오른쪽 ‘안’과 테두리가 잘렸다.

UnityPy로 기존 패치의 Sprite를 디코딩해 같은 잘림을 재현했다. 텍스처 픽셀만
대조하던 종전 검증은 이 문제를 잡지 못했다. 과거의 ‘타이틀 확인 완료’ 기록은
로고 윤곽까지 온전하다는 보장이 아니었으며, 이 기록으로 바로잡는다.

## 수정 범위

`tools/title_sprite.py`에서 한국어가 대체하는 CN Sprite 하나만 사각형 메시로
바꾼다. 4개 꼭짓점·2개 삼각형이 전체 1,024×1,024 텍스처를 표시한다.
기존 rect, pivot, pixels-per-unit, UI 배치는 유지한다. 이미지 픽셀을 다시 그리거나
글자를 줄이지 않았으며 다른 언어의 Sprite·텍스처도 그대로다.

이전 1.0.10 패치와의 차이는 로고 번들 및 그 CRC·크기를 담은 catalog 두 파일이다.
번들 내부에서 바뀐 객체는 Sprite `8640865309597887` 하나뿐이다.
Texture2D `2994417245854802111`의 직렬화 바이트도 이전 패치와 일치한다.

## 검증

- 기존 패치가 새 Sprite 검사에 실패하는 것을 확인했다.
- 수정 Sprite의 크기와 RGBA 픽셀 전체가 텍스처와 일치한다.
- 메시의 4개 꼭짓점, 2개 삼각형, 전체 범위 UV와 좌표 변환을 검사했다.
- 같은 번들의 다른 모든 객체와 Sprite의 배치 정보가 그대로임을 확인했다.
- 1.0.10 검수 사본의 전체 화면과 창 모드에서 글자·귀·테두리 전체를 확인했다.
- 7,436개 번역, 90개 정적 문구, 폰트·튜토리얼·번들 CRC 검증도 통과했다.

로컬 증거는 `work/title-audit/verification.json`, `patched-sprite-before.png`,
`patched-sprite-after.png`, `work/player-title-fix-qa.log`에 있다.
이미지 두 파일은 리소스에서 디코딩한 Sprite이며 게임 스크린샷은 아니다.

## 업데이트

게임을 종료하고 r2 인스톨러에서 **원상 복구 → 한국어 패치 적용**을 실행한다.
기존 v1 패치 위에 바로 덮어쓰면 거부된다. 새 설치라면 바로 적용하면 된다.
원본 백업·저장 데이터를 유지하며, 기존 공개 배포 파일도 별도로 보존한다.
