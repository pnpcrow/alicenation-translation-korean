# 1.0.10 Steam 빌드 26123177 대응

2026-10-23에 확인한 최신 설치본은 Steam 빌드 26123177이며 게임 표기는 1.0.10이다.
이전 빌드 26075487과 실행 파일·globalgamemanagers·GameAssembly·IL2CPP 메타데이터가
모두 같다. 이번 업데이트는 리소스만 바뀌었으므로 별도 프로필 `1.0.10-b26123177`로 구분한다.

## 원본과 변경 범위

- 앱 3755350 / 디포 3755351 / 매니페스트 `9197663091930136135`
- Steam 매니페스트의 경로·크기·SHA-1 및 로컬 SHA-256으로 확인한 원본 398파일, 647,856,060바이트
- 기존 패치가 남은 23파일은 이번 Steam 원본과 일치하는 백업으로 작업 사본을 구성
- 동일 경로 4파일 변경: boot.config, resources.assets, Addressables catalog.json·settings.json
- 폰트와 튜토리얼 아틀라스 번들 각각 교체. 나머지 원본 파일은 이전 빌드와 같다.
- Unity 파일 374개를 분석했으며 읽기 오류는 없다.

## 번역과 그래픽

일본어·영어·번체 번역표는 각각 7,438항목이며 간체는 1,635항목이다.
네 언어 모두 추출·재직렬화가 무손실이다. 일본어 기준으로 블랙잭 안내 키 1개가
교체되었다. 점수 위치가 “맨 오른쪽”에서 “맨 왼쪽”으로 수정되어 한국어도 이에 맞췄다.
영어·번체도 같은 수정이다. 줄바꿈 표식과 나머지 안내는 유지했다.

간체·번체의 `CardInfo_info_WingedFig`에는 오타 수정이 있다. 일본어·영어는 바뀌지
않았으며, 기존 한국어 “그 눈이 적의로 불타고 있다…”도 수정된 의미에 부합해 유지했다.
새로운 표 밖 문구는 없으며 기존 106개를 그대로 적용한다.

튜토리얼 아틀라스는 텍스처 ID와 배치가 바뀌었지만 Sprite 52개 이름·크기는 같다.
각 Sprite를 디코딩해 비교하면 실제 픽셀이 바뀐 것은 `HelpPointer1` 한 개다.
새 그림은 왼쪽의 점수를 보여 주며 번역할 글자가 없다. 새 원본을 그대로 보존한다.
나머지 51개 Sprite 픽셀은 동일하고, 기존 이미지 생성 결과 25개를 새 배치에 재삽입한다.
다른 한글화 이미지 18개와 타이틀 로고의 전체 사각 Sprite 수정도 유지한다.
교체된 폰트 번들에는 WinkySans 아틀라스 변경이 있어 새 원본에 한글 폰트 대체 경로를 적용한다.

## 같은 버전·실행 파일의 빌드 구분

이번에는 기존 두 검증 파일만으로 이전 빌드와 구분할 수 없다. 인스톨러 1.2.3과
제작 도구는 패치가 수정하지 않는 `alicenation_Data/StreamingAssets/aa/settings.json`도 확인한다.

- 26075487 settings SHA-256: `419c934fb56bd1815d8aa65b8825603d0f5c865aa3344402e13aadaee446d99a`
- 26123177 settings SHA-256: `02a720f4e431be900805d95bc0b0ce7970f99f98be3a30b69e8b6bd296b97998`

새 프로필의 세 검증 파일 중 하나가 누락되거나 중복되면 패키지를 거부한다.
통합 패키지에서 이전 두 검증 파일도 일치하는 경우에는 추가 콘텐츠 해시까지
일치하는 새 프로필을 선택한다. 이후 모든 패치 대상 원본 해시를 다시 확인한다.
새 백업은 `backup/1.0.10-b26123177/`에 보관한다. 기존 설치 기록과 백업은 보존한다.

이전 설치 기록은 두 검증 파일만 포함할 수 있으므로, 업데이트된 resources.assets를
과거 빌드로 강제 복구하지 않는 것도 테스트한다. 새 settings가 변조되면 새 패치의
설치·복구를 모두 중단하고 파일을 그대로 보존한다.

GameAssembly와 메타데이터 전체 바이트가 이전 빌드와 같아 검증된 LocalizationText
오프셋 `0x51CC50`과 함수 해시를 유지한다. 패치를 만들 때 함수 해시도 다시 검사한다.
Windows에서 길어진 빌드별 백업 경로를 읽을 수 있도록 원본 구성 도구에 확장 경로 지원을 추가했다.
