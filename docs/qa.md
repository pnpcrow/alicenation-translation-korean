# 검증 기록

## 2026-10-16: 첫 한국어 화면 확인

원본을 복제한 `work/game-preview`에서 시험 빌드를 실행했다. 배포용 완성본이 아니다.
315개 번역과 학교안심 그림일기 TTF, 한국어 타이틀을 넣은 빌드로 확인했다.

- v1.0.5 타이틀 화면에 생성형 이미지로 만든 `앨리스와 피안` 로고가 표시됨.
- 시작, 이어하기, 대화 기록, 언어, 종료 메뉴의 한국어 표시를 육안 확인함.
- 언어 선택창에서 간체 중국어 위치가 `한국어`로 표시됨.
- 영어를 선택하면 영문 메뉴와 기존 영문 타이틀로 전환됨.
- 시험 실행 로그에서 예외, 글리프 누락, CRC 불일치, 로드 실패가 발견되지 않음.
- 시험 실행 종료 후 시험 전 언어 설정을 복원함. 저장 슬롯은 건드리지 않음.

글꼴의 원본 TTF 바이트는 수정하지 않았다. 현대 한글 11,172자 지원을 확인했다.
기존 Lolita의 일부 한글이 혼용되지 않도록 기존 글꼴의 한글 매핑과 TMP 캐시에서만
한글을 제외하고, 독립적인 동적 TMP 한국어 폴백 글꼴을 연결했다.

## 2026-10-17: 최종 인스톨러 GUI 검증과 표시 개선

1.0.5 v1 데이터 패키지(26개 파일)로 CLI 설치·복구를 두 차례 반복했다.
매번 398개 원본 해시가 복원되고 무관한 파일이 보존되었다.
GUI에서도 게임 사본 경로를 입력해 설치 후 26개 결과 해시를 확인하고,
원상 복구 버튼을 눌러 전체 398개 원본 해시가 일치함을 확인했다.
진행 중 버튼 비활성화와 완료/복구 안내문, 로그 및 백업 안내의 배치도 확인했다.

게임이 실행 중일 때의 별도 테스트 실행은 프로세스 보호로 거부되었다.
최종 단위 테스트는 게임 종료 후 실행해야 한다.

실행 검수에서 프롤로그의 ‘방랑자야’가 음절 중간에 줄바꿈되었다.
TMP Settings(1496)의 마지막 직렬화 bool인 m_UseModernHangulLineBreakingRules를
확인하여 활성화했다. 원본 300바이트의 SHA-256을 검사한 뒤 마지막 bool만 변경하고,
검증에서는 나머지 299바이트가 동일한지 확인한다.
참고: https://docs.unity3d.com/ja/Packages/com.unity.textmeshpro%403.0/api/TMPro.TMP_Settings.useModernHangulLineBreakingRules.html

기존 Rust const 바이트 슬라이스가 최적화 빌드에 페이로드를 세 번 포함하는 것을
실행 파일의 바이트 검색으로 확인했다. static으로 바꾸어 공유하도록 수정했다.
이 두 수정 이후 데이터 패키지와 인스톨러/ZIP은 다시 생성한다.

재실행한 최종 리소스에서 프롤로그의 ‘방랑자야.’ 전체가 둘째 줄로 이동하여
단어 중간 분리가 해소되었음을 확인했다. 한국어 선택 항목, 타이틀 버전 1.0.5,
인물 이름과 두 줄 대사의 표시도 확인했다. 긴 퀘스트 도움말은 오른쪽 패널을
스크롤하면 마지막 ‘힌트 버튼을 눌러 보세요.’까지 읽을 수 있다.
초반 튜토리얼의 심상·카드 설명·카드 툴팁과 한국어 도움말 이미지도 확인했다.
모든 분기와 엔딩의 전체 플레이 검수는 수행하지 않았다.
