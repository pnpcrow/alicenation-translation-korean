# 검증 기록

## 2026-10-16: 첫 한국어 화면 확인

원본을 복제한 `work/game-preview`에서 시험 빌드를 실행했다. 배포용 완성본이 아니다.
315개 번역과 학교안심 그림일기 TTF, 한국어 타이틀을 넣은 빌드로 확인했다.

- v1.0.5 타이틀 화면에 생성형 이미지로 만든 `앨리스와 피안` 로고가 표시됨.
- 시작, 이어하기, 대화 기록, 언어, 종료 메뉴의 한국어 표시를 육안 확인함.
- 언어 선택창에서 간체 중국어 위치가 `한국어`로 표시됨.
- 영어를 선택하면 영문 메뉴와 기존 영문 타이틀로 전환됨.
- 시험 실행 로그에서 예외, 글리프 누락, CRC 불일치, 로드 실패가 발견되지 않음.
- 시험 실행 종료 후 시험 전 언어 설정을 복원함. 저장 슬롯은 건드리지 않음.

글꼴의 원본 TTF 바이트는 수정하지 않았다. 현대 한글 11,172자 지원을 확인했다.
기존 Lolita의 일부 한글이 혼용되지 않도록 기존 글꼴의 한글 매핑과 TMP 캐시에서만
한글을 제외하고, 독립적인 동적 TMP 한국어 폴백 글꼴을 연결했다.

## 남은 검증

대사·카드·도움말의 줄바꿈과 잘림, 장시간 플레이 중 동적 아틀라스 확장,
모든 그래픽의 한국어화, 게임 내 설정창의 두 번째 언어 버튼,
최종 인스톨러 설치·복구 및 실패 복구는 별도로 검증해야 한다.

## 2026-10-17: 도움말 이미지 직렬화 확인

1,755개 번역을 포함한 초안 빌드에서 15개 파일 해시, CN 테이블 7,410개 항목,
한국어 이미지 10개의 재삽입 픽셀, Addressables 번들 12개 CRC/크기를 검증했다.
미번역 대사는 일본어 임시 대체이며 정식 빌드에서는 허용하지 않는다.
도움말 이미지의 한글과 배치를 원본과 대조했으며 실제 도움말 화면 검증은 남아 있다.

## 2026-10-17: Rust 인스톨러 시험

델타 패키지를 제작하고 깨끗한 게임 사본에서 두 차례 설치·복구했다.
15개 패치 파일의 적용 해시와 복구 후 원본 전체 398개 해시가 일치했다.
중복 설치는 안전하게 무시하고, 관련 없는 파일과 실제 Steam 원본은 보존됐다.

10개 단위 테스트에서 두 번째 파일 교체 실패 후 자동 복구, 실제 Windows 파일 잠금,
작업 중단 후 패키지 없이 복구, 잘못된 게임 버전, 손상된 패키지/백업,
다른 패치의 변경 보존, 동시 실행 차단, 경로 이탈 차단을 확인했다.
GUI와 최종 배포 패키지 검증은 별도 단계다.

## 2026-10-17: 대사 확장 초안 확인

대사 0–2224번을 포함해 총 3,855/7,410개 항목을 번역한 초안을 다시 빌드했다.
`validate_translations.py`에서 변수·서식·원문 연결 검사 오류는 없었다.
`verify_patch.py`에서 15개 파일 해시, 7,410개 텍스트 레코드, 이미지 10개의
직렬화 후 픽셀, 번들 12개의 CRC와 크기가 모두 일치했다.

패치된 `resources.assets` 안의 OPPOSans-M, PerfectDOSVGA437, Lolita,
학교안심 그림일기의 내장 폰트 cmap을 읽어 번역에 사용한 모든 공백 외 문자를
대조했다. 어느 내장 폰트에도 없는 문자는 0개였다. 이는 폰트 파일의 문자
지원 확인이며 실제 TMP 폴백 경로와 화면 배치의 완전한 검증은 아니다.

나머지 3,555개 대사는 일본어 임시 대체 상태다. `work/patched`는 이 초안으로
갱신했지만, 기존 인스톨러 시험용 패키지와 GUI 내장 페이로드는 앞선 1,755개
번역 빌드이므로 현 상태의 최신 번역 배포물로 취급하지 않는다.

## 2026-10-17: 3장 대사 및 추가 그래픽 통합

4,755/7,410개 번역, 이미지 18개를 포함한 초안을 다시 빌드했다.
21개 파일 해시, 텍스트 7,410개 재읽기, 이미지 18개 픽셀,
Addressables 번들 18개 CRC/크기 검증이 통과했다.

`resources.assets`에 텍스처를 추가해도 앞선 대사·폰트 수정이 유지되도록 빌드를 고쳤다.
같은 경로를 여러 번 저장하더라도 매니페스트에는 최종 해시 한 개만 남긴다.
재읽기 검증에서 리소스 파일과 폰트 번들 양쪽의 폰트 원본 바이트, TMP 폴백 우선순위,
동적 아틀라스 설정, 기존 폰트의 한글 제거와 새 폰트의 한글 11,172자 지원을 확인했다.
이는 직렬화 상태에 대한 회귀 검사이며 실제 화면에서의 폴백·줄바꿈 검수와 구분한다.

나머지 대사 2,655개는 일본어 임시 대체다. 튜토리얼 아틀라스와 게임 내 검수,
완성된 리소스를 포함한 최종 인스톨러 제작은 아직 남아 있다.

## 2026-10-17: 튜토리얼 아틀라스 24장 통합

52장 중 24장 번역, 27장 보존, CardMap 1장 보류 상태다.
22개 파일 해시, 텍스트 7,410개, 한글 폴백 두 곳, 개별 이미지 18개,
튜토리얼 52개 이미지/메타데이터, 번들 19개 CRC/크기 검사가 통과했다.
검증은 빌드 완료 후 수행했다. 빌드 중 이전 매니페스트로 실행한 한 차례 검사는
중간 resources.assets 해시 불일치로 종료되었으며 완성 빌드의 오류는 아니었다.

원본과 한글화 결과를 같은 300×300 크기로 나란히 놓고 3장 비교표로 확인했다.
RestEnd1의 아래쪽 세 번째 수량은 원본을 최근접 확대하여 **6**으로 확정했다.
첫 생성물이 맞았으며, 2로 바꾼 후속 수정안은 제외했다.
튜토리얼 캡션은 `그림이 사라졌다냥...`, 제작 카드는 번역표와 동일하게
`연금술을 시작하자!`, 초소 이름은 `감시 중인 초소`로 표기했다.

Rust `cargo test --all-targets`의 기존 패치/복구 테스트 10개가 통과했다.
그래픽 진행률을 Rust 패키저에도 필수 입력으로 추가했다.
`test_pack_gate.py`에서 텍스트가 7,410개 모두 번역된 상태라도 그림이 1장 남으면
배포 패키지를 거부하는지 확인했다. 그래픽 검수 항목 누락·잘못된 합계도 거부하며
어느 경우에도 출력 패키지를 생성하지 않았다.
실제 플레이 화면 검수와 최종 인스톨러의 최신 리소스 포함은 아직 남아 있다.
