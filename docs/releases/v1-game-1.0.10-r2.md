# 앨리스와 피안 한국어 패치 v1 r2 — 게임 1.0.10 로고 수정판

**이 패치는 GPT Astra를 사용한 AI 번역의 결과물입니다.** 일본어 리소스를 기준으로
영어·중국어를 비교했으며, 기존 한글화 그래픽은 이미지 생성 기능으로 제작했습니다.
비공식 패치이며 오역이나 문맥상 어색한 표현이 남아 있을 수 있습니다.

## 수정 내용

메인 화면에서 한글 로고의 귀·글자·테두리 일부가 잘리던 문제를 수정했습니다.
로고 이미지 자체는 온전했지만, 중국어 로고 윤곽에 맞춘 Sprite 표시 정보가 남아
한글 그림을 잘라내고 있었습니다. 전체 이미지가 표시되도록 수정했습니다.
이미지 픽셀, 크기·배치, 번역 7,436개, 다른 한글화 리소스는 기존 v1과 같습니다.

게임 **Windows 1.0.10 전용**, Rust 인스톨러 **1.2.1**입니다.
r2는 로고 수정 배포 리비전이며 인스톨러 내부 패치 형식은 v1을 유지합니다.

## 설치와 기존 v1에서 업데이트

`Alicenation-1.0.10-Korean-v1-r2.zip`을 받아 압축을 풀고
`Alicenation-Korean-v1.exe`를 실행하세요.

1. 게임을 종료하고 `alicenation.exe`가 있는 폴더를 선택합니다.
2. **이미 1.0.10용 v1이 설치되어 있다면 먼저 원상 복구를 누릅니다.** 이 수정 인스톨러로 복구할 수 있습니다.
3. **한국어 패치 적용**을 누릅니다. 새 설치라면 복구 없이 바로 적용하면 됩니다.
4. 게임 언어 설정에서 **한국어**를 선택합니다. 기존 중국어 간체 슬롯을 대체합니다.

원상 복구도 같은 인스톨러로 실행합니다. `.alicenation-korean` 원본 백업을
보존하세요. 저장 데이터는 변경하지 않습니다. 기존 v1 위에 바로 설치하면 거부합니다.
다른 게임 버전에서 Steam이 자동 업데이트했다면 먼저 게임 파일 무결성을 확인하세요.
게임 본편은 포함하지 않으며 기존 배포 파일은 각 릴리즈에 보존했습니다.

## 검증

- 기존 잘림을 Sprite 디코딩으로 재현하고 새 검사가 이를 탐지함을 확인
- 수정 Sprite 전체 픽셀과 메시·UV, 다른 언어 로고·배치 정보 보존 확인
- 실제 게임의 전체 화면·창 모드에서 로고의 귀·글자·테두리 전체 표시 확인
- 기존 번역·폰트·튜토리얼·번들 CRC 검사 통과
- 최종 실행 파일로 기존 v1 복구 및 수정본 설치·중복 설치·복구 두 차례 검증
