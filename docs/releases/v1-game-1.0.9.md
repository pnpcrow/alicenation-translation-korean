# 앨리스와 피안 한국어 패치 v1 — 게임 1.0.9용

**이 패치는 GPT Astra를 사용한 AI 번역의 결과물입니다.** 일본어 리소스를 기준으로
영어·중국어를 비교했으며, 그래픽은 이미지 생성 기능으로 한글화했습니다.
공식 한국어판이 아닌 비공식 패치이며, 오역이나 문맥상 어색한 표현이 남아 있을 수 있습니다.

## 다운로드와 설치

`Alicenation-1.0.9-Korean-v1.zip`을 받아 압축을 풀고 `Alicenation-Korean-v1.exe`를 실행하세요.
게임을 종료한 뒤 `alicenation.exe`가 있는 폴더를 선택하고 **한국어 패치 적용**을 누릅니다.
게임 설정에서는 **한국어**를 선택합니다. 기존 중국어 간체 슬롯을 대체합니다.

복구는 같은 인스톨러의 **원상 복구**로 실행합니다. 게임 폴더의 `.alicenation-korean`
백업을 보존하세요. 저장 데이터는 변경하지 않습니다. 게임 본편은 포함하지 않습니다.

## Steam이 먼저 업데이트한 경우

이전 패치를 복구하기 전에 게임이 업데이트됐다면 Steam에서 **게임 속성 → 설치된 파일 →
게임 파일 무결성 확인**을 실행한 다음 이 배포판을 적용하세요. 새 버전 원본이 모두
확인되면 이전 설치 기록을 `history`에 보관하고 기존 버전 백업도 유지합니다.
업데이트된 파일을 이전 버전으로 강제로 되돌리지는 않습니다.

이 배포판은 검증한 **Windows 게임 1.0.9 전용**입니다. 1.0.8은 검증하지 않았으며
지원하지 않습니다. 기존 1.0.5·1.0.6용 배포판은 각각의 릴리즈에 보존했습니다.
