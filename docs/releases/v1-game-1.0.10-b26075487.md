## 설치와 복구

`Alicenation-1.0.10-b26075487-Korean-v1.zip`을 받아 압축을 풀고
`Alicenation-Korean-v1.exe`를 실행하세요.

1. 게임을 종료합니다.
2. **이전 패치를 적용한 상태에서 Steam이 업데이트했다면 먼저 Steam → 게임 속성 → 설치된 파일 → 게임 파일 무결성 확인을 실행합니다.**
3. 인스톨러에서 `alicenation.exe`가 있는 폴더를 선택하고 **한국어 패치 적용**을 누릅니다.
4. 게임의 언어 설정에서 **한국어**를 선택합니다. 기존 중국어 간체 슬롯을 대체합니다.

복구는 게임을 종료하고 같은 인스톨러의 **원상 복구**로 진행합니다.
게임 폴더의 `.alicenation-korean` 백업을 보존하세요. 새 원본이 모두 확인되면
이전 설치 기록과 백업을 남기고 설치합니다. 저장 데이터는 변경하지 않습니다.
게임 본편은 포함하지 않으며 기존 게임이 필요합니다.
