# 앨리스와 피안 한국어 패치 v1 — 게임 1.0.5용

**GPT Astra를 사용한 AI 번역의 결과물입니다.** 일본어 리소스를 기준으로 영어·중국어를 비교해 번역했고, 그래픽은 이미지 생성 기능을 활용해 한글화했습니다. 공식 한국어판이 아닌 비공식 패치이며 오역이나 어색한 표현이 남아 있을 수 있습니다.

Windows 게임 **1.0.5 전용** 배포판입니다. 1.0.6 사용자는 [1.0.6용 릴리즈](https://github.com/pnpcrow/alicenation-translation-korean/releases/tag/v1-game-1.0.6)를 사용하세요.

## 포함 내용

- 텍스트 7,410항목, 별도 화면 문구 90개, 이미지 43개 한글화
- 학교안심 그림일기 글꼴과 한국어 단어 단위 줄바꿈
- 중국어 간체 슬롯을 **한국어**로 교체
- Rust 인스톨러 1.1.0: 원본 버전·해시 검사, 원본 백업, 패치 적용, 원상 복구
- 이전 1.0.5 전용 v1 인스톨러의 설치 기록 복구 지원

## 설치와 복구

1. 아래 Assets의 `Alicenation-1.0.5-Korean-v1.zip`을 내려받고 압축을 풉니다.
2. 게임을 종료하고 `Alicenation-Korean-v1.exe`를 실행합니다.
3. `alicenation.exe`가 있는 폴더를 선택해 **한국어 패치 적용**을 누릅니다.
4. 게임의 언어 설정에서 **한국어**를 선택합니다.

복구할 때는 게임을 종료한 뒤 같은 인스톨러에서 **원상 복구**를 누릅니다. 원본 백업은 게임 폴더의 `.alicenation-korean/backup/1.0.5`에 보관됩니다. 복구 전에는 백업을 지우지 마세요. 저장 데이터는 변경하지 않습니다.

게임 업데이트 전에 먼저 복구하고, 업데이트 후 해당 버전의 패치를 적용하세요. 인스톨러 1.1.0으로 적용한 패치는 1.1.0으로 복구해야 합니다. 이미 설치된 v1 패치의 내용은 동일하므로 다시 적용할 필요가 없습니다.

## 검증과 배포 파일

번역표 누락·변수·서식, 폰트·이미지·파일 무결성을 검사했습니다. 이 배포 실행 파일로 실제 게임 사본에서 설치·중복 설치·복구를 두 차례 반복하고, 복구 후 원본 파일 398개의 해시 일치를 확인했습니다. 이전 인스톨러로 설치한 패치의 복구도 확인했습니다.

타이틀·언어 선택·프롤로그·초반 튜토리얼·도움말을 확인했지만 모든 이야기 분기와 엔딩을 끝까지 플레이한 것은 아닙니다. 자세한 기록은 [검증 문서](https://github.com/pnpcrow/alicenation-translation-korean/blob/v1-game-1.0.5/docs/qa.md)에 있습니다.

- `Alicenation-1.0.5-Korean-v1.zip`: 실행 파일, 사용 안내, 글꼴·라이브러리 라이선스
- `Alicenation-1.0.5-Korean-v1.zip.sha256`: ZIP의 SHA-256 체크섬

GitHub의 자동 생성 `Source code` 파일은 제작 소스이며 설치용 ZIP이 아닙니다. 게임 본편은 포함하지 않습니다. 게임과 원본 리소스의 권리는 원저작자에게 있습니다.
