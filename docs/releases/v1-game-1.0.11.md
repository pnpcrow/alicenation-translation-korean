# 앨리스와 피안 한국어 패치 v1 — 게임 1.0.11

**이 패치는 GPT Astra를 사용한 AI 번역의 결과물입니다.** 일본어 리소스를 기준으로
영어·중국어를 비교했으며, 기존 한글화 그래픽은 이미지 생성 기능으로 제작했습니다.
비공식 패치이며 오역이나 문맥상 어색한 표현이 남아 있을 수 있습니다.

## 설치와 복구

`Alicenation-1.0.11-Korean-v1.zip`을 내려받아 압축을 풀고
`Alicenation-Korean-v1.exe`를 실행하세요.

1. 게임을 종료합니다.
2. **기존 패치를 적용한 상태에서 Steam이 업데이트했다면 먼저 Steam → 게임 속성 → 설치된 파일 → 게임 파일 무결성 확인을 실행합니다.**
3. 인스톨러에서 `alicenation.exe`가 있는 폴더를 선택하고 **한국어 패치 적용**을 누릅니다.
4. 게임 언어에서 **한국어**를 선택합니다. 기존 중국어 간체 슬롯을 대체합니다.

원상 복구는 게임을 종료하고 같은 인스톨러의 **원상 복구**로 진행합니다.
게임 폴더의 `.alicenation-korean`을 지우지 마세요. 이전 설치 기록과 원본 백업은
보존하고 새 버전의 백업을 따로 만듭니다. 저장 데이터는 변경하지 않습니다.
게임 본편은 포함하지 않으며, 이전 버전용 배포판은 기존 릴리즈에 남아 있습니다.

저장 슬롯의 장 번호는 공용 문자열을 사용하므로 다른 언어를 선택해도 한국어로
표시됩니다. 공용 연출·그림의 한국어 표시도 이전 패치와 같습니다.
