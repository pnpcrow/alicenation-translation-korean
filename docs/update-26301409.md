# 1.0.11 Steam 빌드 26301409 대응

2026-10-30에 확인한 설치본은 게임 내 버전 1.0.11, Steam 빌드 26301409다.
이전 빌드 26208729와 구분하는 프로필은 `1.0.11-b26301409`다.

## 원본과 변경 범위

- 앱 3755350 / 디포 3755351 / 매니페스트 `7426157566445852822`
- Steam 매니페스트의 경로·크기·SHA-1과 로컬 SHA-256으로 확인한 원본 398파일, 647,881,096바이트
- 이전 패치가 남은 28파일은 이번 Steam 원본과 동일한 검증된 백업으로 작업 사본을 구성
- 변경 파일은 resources.assets, Addressables settings.json, boot.config 세 개뿐이며 파일 추가·삭제 없음
- Unity 파일 374개 분석, 파일 읽기 오류 없음
- 일본어·영어·번체 7,500항목, 간체 1,635항목은 이전 빌드와 모두 동일하며 무손실 추출·재직렬화 확인

resources.assets에서 변경된 오브젝트는 `Chapter6`(1507)과 `ChapterStory`(1514)
두 개뿐이다. 이야기 스크립트 17개를 무손실 파싱해 비교했다.

- Chapter6 / script2 / 43번 명령: 메리의 말풍선에서 `mood:e` 인자 제거
- ChapterStory / Story2_2 / 83번 명령: 의사의 대사 키 끝 오탈자 `吧了！` → `吧！` 수정

번호는 각 블록에서 0부터 센 명령 위치다. 두 변경 모두 최신 원본대로 보존한다.
boot.config는 build-guid만 바뀌었고, settings.json은 m_SettingsHash만 바뀌었다.

## 번역표에 없는 수정 대사 키

의사 대사의 키는 스크립트에서만 바뀌었으며 네 언어 번역표에는 새 키가 없다.
이전 방식대로 일본어 번역표 7,500항목만 삽입하면 이 줄은 번역을 찾지 못한다.
새 키 한 개를 기존 일본어 기반 한국어 번역으로 연결하여 CN 표에 추가한다.

> 아, 지금 갈 테니까 거기서 기다려! 한 발로 뛴다고? 안 돼, 2년 뒤에나 해!

일본어와 영어의 기존 대응 문장이 동일한 뜻임을 확인했다. 새 키는 기존 키에서
중복된 한 글자만 제거한 것이다. 일본어·영어·번체 번역표와 이야기 명령은
변경하지 않으며 CN 표만 7,501항목이 된다. 번역 범위는 **일본어 기준 7,500항목과
실행 중 대사 키 연결 1개**로 구분해 기록한다.

`tools/runtime_aliases.py`는 기존 키와 고정된 일본어 원문, 키 충돌 여부, 이야기
오브젝트·블록·명령 위치·화자·새 키를 검증한다. 빌드 및 패치 재검증에서 원본과
패치 양쪽의 해당 명령을 확인한다. Rust 패키저도 이 빌드의 키 연결 개수가 1이
아니면 배포물을 만들지 않는다.

## 그래픽·코드와 빌드 판별

모든 그래픽·프리팹·폰트 번들, 실행 파일, GameAssembly, globalgamemanagers와
metadata는 이전 빌드와 바이트 단위로 같다. 기존 이미지 생성 결과 43개, 화면
문구 164개, 로고의 전체 사각 메시, 한글 폰트와 장 번호 번역을 유지한다.
변경되지 않은 그래픽은 다시 생성하지 않는다.

- 새 settings.json SHA-256: `419c934fb56bd1815d8aa65b8825603d0f5c865aa3344402e13aadaee446d99a`
- 새 resources.assets SHA-256: `fe41933597104d3552c01ef0f783fb4a8e1259473f594cada31371543b56b8b9`
- GameAssembly 함수와 metadata 문자열 위치는 [이전 분석](update-26208729.md)의 검증값 그대로다.

인스톨러 1.2.5는 실행 파일·globalgamemanagers·settings.json과 패치 대상 29개의
원본 해시를 검사한다. 같은 1.0.11이어도 이전 빌드에는 적용하지 않으며,
새 백업은 `backup/1.0.11-b26301409/`에 보관한다. 이전 설치 기록·백업을 유지한다.
