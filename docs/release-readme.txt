앨리스와 피안 — 한국어 패치 v1
대상 게임: Alice Nation / Alicenation, Windows 1.0.5

설치
1. 게임을 종료합니다.
2. Alicenation-Korean-v1.exe를 실행합니다.
3. alicenation.exe가 있는 게임 폴더를 선택합니다.
4. [한국어 패치 적용]을 누르고 완료 메시지를 기다립니다.
5. 게임의 언어 설정에서 [한국어]를 선택합니다.
   기존 중국어 간체 자리를 한국어로 바꾸는 패치입니다.

원상 복구
게임을 종료하고 같은 인스톨러에서 게임 폴더를 지정한 뒤 [원상 복구]를 누릅니다.
원본 백업은 게임 폴더의 .alicenation-korean/backup에 보관됩니다.
복구 전에는 이 백업 폴더를 지우지 마세요. 저장 데이터는 변경하지 않습니다.
설치가 중단되었다면 게임을 닫고 [원상 복구]를 실행한 뒤 다시 적용합니다.

호환성
게임 1.0.5의 검증된 원본에 적용합니다. 다른 버전이나 변경된 파일에는 적용을 거부합니다.
게임이 업데이트되면 해당 버전용 패치를 사용해야 합니다.
다른 한글 패치나 모드를 겹쳐 설치하지 마세요.

포함 내용
일본어 기준 텍스트 7,410항목, 별도 화면 문구 90개, 한국어 이미지 43개.
영어와 중국어 리소스를 비교하며 번역했습니다.
공용 연출·그림은 다른 언어를 골라도 한국어로 표시될 수 있습니다.
학교안심 그림일기 글꼴을 사용하며, 원본 글꼴과 라이브러리 고지는 licenses에 있습니다.
이 패치는 게임 본편을 포함하지 않습니다. 기존 게임이 필요합니다.

검수 범위
전체 번역표의 누락·변수·서식, 이미지 재삽입, 폰트, 파일 무결성과 설치·복구를 검사했습니다.
실제 플레이의 모든 분기와 엔딩을 끝까지 검수한 것은 아닙니다.

명령줄
Alicenation-Korean-v1.exe status --game "게임 폴더"
Alicenation-Korean-v1.exe patch --game "게임 폴더"
Alicenation-Korean-v1.exe restore --game "게임 폴더"

게임과 원본 리소스의 권리는 원저작자에게 있습니다.
