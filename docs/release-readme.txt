앨리스와 피안 — 한국어 패치 v1
대상 게임: Alice Nation / Alicenation, Windows 1.0.5 / 1.0.6
인스톨러 1.1.0 — 게임 버전 자동 판별

이 패치는 GPT Astra를 사용한 AI 번역의 결과물입니다.
일본어를 기준으로 영어·중국어를 비교했고, 그래픽은 이미지 생성 기능으로 한글화했습니다.
공식 한국어판이 아닌 비공식 패치이며 오역이나 어색한 표현이 남아 있을 수 있습니다.

설치
1. 게임을 종료합니다.
2. Alicenation-Korean-v1.exe를 실행합니다.
3. alicenation.exe가 있는 게임 폴더를 선택합니다.
4. [한국어 패치 적용]을 누릅니다. 버전을 자동 판별하여 적용합니다.
   완료 메시지가 표시될 때까지 기다립니다.
5. 게임의 언어 설정에서 [한국어]를 선택합니다.
   기존 중국어 간체 자리를 한국어로 바꾸는 패치입니다.

원상 복구
게임을 종료하고 같은 인스톨러에서 게임 폴더를 지정한 뒤 [원상 복구]를 누릅니다.
원본 백업은 게임 폴더의 .alicenation-korean/backup 안에 버전별로 보관됩니다.
복구 전에는 이 백업 폴더를 지우지 마세요. 저장 데이터는 변경하지 않습니다.
설치가 중단되었다면 게임을 닫고 [원상 복구]를 실행한 뒤 다시 적용합니다.

호환성
게임 1.0.5와 1.0.6의 검증된 원본에 적용합니다. 다른 버전이나 변경된 파일에는 적용을 거부합니다.
게임을 업데이트하기 전 먼저 원상 복구하세요. 업데이트 후 다시 패치를 적용합니다.
이미 패치한 게임이 먼저 업데이트되었다면 복구를 강제로 진행하지 않습니다.
Steam 파일 무결성 검사로 새 버전 원본을 확보하고 기존 백업을 보존한 채 상태를 확인하세요.
이전 1.0.5 전용 v1 인스톨러로 설치한 패치도 이 통합 인스톨러에서 복구할 수 있습니다.
통합 인스톨러로 적용한 패치는 이 통합 인스톨러로 복구하세요.
다른 한글 패치나 모드를 겹쳐 설치하지 마세요.

포함 내용
일본어 기준 텍스트 7,410항목(1.0.5) / 7,417항목(1.0.6), 별도 화면 문구 90개, 한국어 이미지 43개.
1.0.6의 템플릿 이름·설명 두 항목은 일본어가 비어 있어 중국어 원문을 참고했습니다.
영어와 중국어 리소스를 비교하며 번역했습니다.
공용 연출·그림은 다른 언어를 골라도 한국어로 표시될 수 있습니다.
학교안심 그림일기 글꼴을 사용하며, 원본 글꼴과 라이브러리 고지는 licenses에 있습니다.
이 패치는 게임 본편을 포함하지 않습니다. 기존 게임이 필요합니다.

검수 범위
전체 번역표의 누락·변수·서식, 이미지 재삽입, 폰트, 파일 무결성과 설치·복구를 검사했습니다.
실제 플레이의 모든 분기와 엔딩을 끝까지 검수한 것은 아닙니다.
