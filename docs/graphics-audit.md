# 그래픽 검수

2026-10-17, `tools/audit_graphics.py`로 Texture2D 1,402개를 추출했다.
픽셀 중복을 제외한 1,108개를 37장 미리보기로 모두 확인했다.
전체 경로·객체 ID·픽셀 해시는 `reference/graphics-audit/index.json`에 있다.
미리보기는 분석용이며 패치에 포함하지 않는다.

## 적용된 수정

- Title_CN: 일본어 타이틀 기준 `앨리스와 피안`. 실제 타이틀 화면 확인 완료.
- Help1, Help2, Help4~Help10: 중국어 UI를 한국어로 교체. 원본 게임 그림을 참조하여 image_gen으로 제작.
- Help3: 번역할 문자가 없어 보존.
- 이미지 10개를 원래 해상도로 Unity에 다시 넣고 픽셀 일치와 12개 번들 CRC를 검증했다.
- 도움말 안에 찍힌 과거 개발 버전 번호는 원본 기록이므로 유지했다.

## 추가로 발견한 대상 (작업 중)

- fallbackImage (미리보기 0004): 텍스처 누락 메시지.
- Rumor (0391): 배경의 `谣言`.
- Illusion (0501): 피안, 자아, 숙명, 잠재의식 등 중국어 배경 문자.
- cg8 / cg8_2 (0102 / 0103): 병원 문 위 `手术中`.
- cg33 / cg33_2 / cg33_3 (0061~0063): 흐린 배경 족자의 `にんげん` 확인 및 한국어화.
- TeachAtlas 두 장 (0581 / 0582): 작은 튜토리얼 스크린샷들이 묶인 아틀라스.
  도움말 Help1~10과 별개이므로 스프라이트 단위로 번역·재삽입해야 한다.

## 유지하는 요소

Unity 및 제작사 로고는 브랜드 표기로 보존한다. 글꼴 아틀라스는 번역 이미지가 아니라
글리프 데이터이므로 폴백 글꼴 방식으로 처리한다. 배경의 룬 문자, 기하학 기호,
숫자, 삽화 속 영문 의류 장식과 달력의 영문 약자는 그림의 일부로 보존한다.
cg40 문패, NextLevelCity 표지판, cg54/cg61 도로 표식은 실제 언어가 아닌
기호로 판단했다. Proof5와 배경의 메모들은 판독 가능한 문장이 없는 장식 선이다.

추가 대상 제작과 게임 내 표시 검증은 아직 완료하지 않았다.
