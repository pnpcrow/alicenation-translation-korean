# 1.1.2 Steam 빌드 26643402 대응

2026-11-14 Steam 설치 기록과 public 브랜치 캐시에서 게임 1.1.2, 빌드
26643402를 확인했다. 앱 3755350, 디포 3755351, 매니페스트는
`8384057307569392237`이다. 원본 398개, 649,936,236바이트를 경로·크기·SHA-1과
SHA-256으로 대조했다. 기존 패치 잔여물 20개의 원본은 검증된 백업에서 확보해
작업 사본을 만들었으며 이 단계에서 Steam 설치본은 수정하지 않았다.

## 리소스 변경

이전 1.1.0 빌드 26613101과 비교하면 같은 경로 8개가 바뀌고 번들 17개가
교체됐다. Unity 파일 374개를 오류 없이 읽었다. 일본어·영어·간체·번체 번역표와
이야기 스크립트 17개를 무손실 파싱했으며 번역표와 이야기 명령에는 변경이 없다.
일본어 기준 7,501항목과 별도 화면 문구 166개를 그대로 사용한다.

왕눈이 설정 `CardEyesConfig`는 79항목에서 71항목으로 바뀌었다. 키 3개가
추가되고 11개가 제거됐으며 유지된 키의 좌표·배율은 동일하다. 새 설정 전체를
그대로 보존한다. 카드·선택·보상·저장 화면 등의 변경 번들도 최신 원본을 사용한다.
변경된 공용 UI에 새 텍스트나 수정된 텍스트는 없다.

텍스처 오브젝트 34개의 변경 중 13개는 디코딩한 픽셀이 동일하다. 나머지는
공용 `Drawing_Toon` 색상 띠 16개와 원본 글꼴 아틀라스 5개다. 색상 띠에는
문자가 없음을 직접 확인했으며 새 원본을 보존한다. Lolita 글꼴에는 375개,
OPPOSans에는 13개 문자의 캐시가 추가됐다. 기존 아틀라스와 새 아틀라스 3개,
비한글 문자 매핑·배치 정보를 그대로 두고 한글 폰트 대체 경로를 적용한다.
기존 한글화 이미지 43개와 로고 잘림 수정에는 변경이 없다.

## 실행 코드와 저장 화면

새 GameAssembly와 metadata를 Il2CppDumper로 분석했다. 한국어 조회 함수
`LocalizationManager.LocalizationText`의 RVA는 `0x51E3A0`, 파일 위치는
`0x51D5A0`이다. 0xB3바이트의 함수 해시를 고정하고 기존과 같은 `+0x59`의
CN 분기 `75 4A` 두 바이트만 바꾼다. 다른 게임 로직은 수정하지 않는다.

metadata의 유일한 `Chapter {0}` 리터럴 위치는 엔트리 `0x6C00`, 데이터
`0x383C9`로 동일하지만 전체 원본 해시가 바뀌어 새 값을 추가했다. 이전 두
metadata와 새 metadata의 정상 변환·원본 보존·변조 입력 거부를 확인했다.
resources의 오브젝트 번호와 TMP 설정은 1.1.0과 같다. 번역·글꼴·줄바꿈 외
모든 resources 오브젝트를 원본 바이트와 대조한다.

- 번역 조회 함수 SHA-256: `12eff59a2e0771a092580a569eaef772229580e5846f7a5dcc3a0cc126d885ff`
